# Pivot Phrases — Sentence Builder

A kid-friendly web app that helps young children practice two- and three-word sentences using **pivot phrases** (carrier phrases) and target words.

## Quick start

```bash
cd pivot-phrases
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Features

- Tap a pivot phrase, then a target word to build a sentence
- Cards animate into the sentence builder slots
- Web Speech API reads each tap and the full sentence on Play
- Celebration confetti and stars when playing a complete sentence
- Category tabs for Animals, Food, and Clothes
- Mobile-first, touch-friendly UI with emoji icons (no reading required)

## Tech stack

- React + TypeScript (Vite)
- Tailwind CSS v4
- Framer Motion

## Build

```bash
cd pivot-phrases
npm run build
npm run preview
```
